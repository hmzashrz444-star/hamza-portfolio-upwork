# Hamza Portfolio — Upwork Edition

My personal design and development portfolio, built with HTML, CSS and JavaScript.

The site includes selected web, brand and motion projects, responsive layouts, custom interactions and canvas-based animation.

## Run locally

Open `index.html` in a browser. There is no build step or package installation.

## Deploy

This is a static site. Import the repository into Vercel and deploy it with the **Other** framework preset. Leave the build command and output directory empty.
